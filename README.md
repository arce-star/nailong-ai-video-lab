# Nailong AI Video Lab

30 秒科幻 AI 视频创作实验仓库。

## 核心概念

> 同一个奶龙，以完全一致的步频、步幅和节奏，持续向右行走；镜头与角色位置基本稳定，而世界每 5 秒发生一次彻底变化。

画面采用横版卷轴（side-scrolling）逻辑：

- 奶龙保持在画面中心附近；
- 奶龙持续向右走；
- 背景向左运动，制造前进感；
- 每 5 秒切换一个 **场景 + 视觉风格**；
- 不要求所有段落统一画风，反而强调“同一运动、不同世界”；
- 走路频率、步伐幅度和节奏尽量严格一致；
- 最终用动感 BGM 把所有世界串成一个整体。

## 当前 30 秒版本

计划制作 6 个 × 5 秒的连续段落。

当前明确的视觉方向包括：

- 樱花场景：适配板绘 / 线描等轻盈风格；
- 月球场景：适配超写实风；
- 南极冰川：可尝试像素风或其他强风格化表达；
- 城市马路：适配数码 / 赛博视觉；
- 数据世界：适配 ASCII / terminal aesthetic；
- 第六段待继续设计，要求“场景与风格天然适配”，不硬凑。

详细设计见 `docs/`。

## 核心难点

### 1. 角色一致性

每一段都必须让观众感觉是“同一个奶龙”。需要控制：

- 体型比例；
- 脸部特征；
- 配色；
- 轮廓；
- 朝向；
- 镜头尺度；
- 角色在画面中的相对位置。

计划通过多视图角色参考、标准侧视图、关键步态帧、颜色卡、轮廓参考等数字资产辅助生成。

### 2. 步态一致性

不同风格之间不能重新设计动作。核心要求：

- 步频一致；
- 步幅一致；
- 重心起伏一致；
- 前后肢运动相位一致；
- 尽量保持同一 walking cycle。

### 3. 世界变化但镜头不断

每 5 秒发生一次“世界跃迁”，但不改变核心镜头逻辑。切换效果优先放到剪辑阶段处理，生成阶段先保证每个 5 秒片段本身稳定。

## 技术路线

同时尝试两条路线：

### Route A — 资产优先

角色参考资产 → 标准 walking cycle → 各风格关键图 → 图生视频 / 参考视频生成 → 剪辑。

### Route B — 直接视频

固定角色参考 → 直接生成 5 秒视频片段 → 多次抽卡 → 选稳定结果 → 剪辑。

最终根据一致性与效率选择，必要时混合使用。

## 仓库用途

这个仓库用于持续记录：

- 创意与视觉设定；
- 场景 × 风格映射；
- 角色数字资产；
- Prompt 版本；
- 生图 / 生视频实验；
- 失败案例；
- ComfyUI 工作流；
- 剪辑与 BGM 节奏；
- 最终参赛材料。

## 当前优先级

1. 锁定 6 个“场景 × 风格”组合；
2. 建立奶龙一致性资产包；
3. 做一套标准 side-view walking cycle；
4. 用两种技术路线各试 1–2 个 5 秒片段；
5. 选定主流程后完成 30 秒 rough cut。
