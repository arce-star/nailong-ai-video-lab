# Project Brief

## Goal
Create a ~30s sci-fi AI video built around a fixed side-scrolling composition.

## Core visual rule
- The main character stays near the center of frame and walks to the right.
- Walking cadence, stride, and rhythm remain consistent.
- The background moves left to create forward motion.
- Every ~5 seconds, both the scene and visual style change.
- Each scene gets a style that naturally fits it; style changes are intentional rather than arbitrary.
- Editing and music provide continuity across the different worlds.

## First version
- Duration: about 30 seconds
- Structure: 6 segments × about 5 seconds
- Camera: side view or near-side view
- Character position: stable near center
- Motion: fixed walking-cycle logic

## Still open
- Final order of the 6 scenes
- Transition style
- Asset-first vs direct-video pipeline
- Final BGM and BPM
- Generation model used for each segment
