# 技术路线与实验计划

## Route A：资产优先

流程：

1. 锁定角色标准图
2. 制作多视图参考资产
3. 制作标准 side-view walking cycle
4. 为每个世界生成关键帧 / 风格定帧
5. 图生视频或 reference-to-video
6. 剪辑拼接
7. 用 BGM 对齐步态与世界切换

优点：
- 一致性更容易控制
- 方便跨模型 / 跨平台
- 后续可重复生成某一段

风险：
- 前期准备工作较多
- 不同视频模型可能仍然改动角色细节

## Route B：直接视频

流程：

1. 固定一张或一组角色参考图
2. 每个世界直接生成约 5 秒视频
3. 多次抽卡
4. 选角色和动作最稳定的一版
5. 剪辑拼接

优点：
- 快速得到成片感
- 适合探索镜头、运动和风格

风险：
- 角色漂移更明显
- 不同片段的 walking cadence 可能不一致
- 后期对齐难度更大

## Route C：混合方案

当前最推荐。

先用 Route B 快速试出视觉方向；一旦发现角色或动作不稳定，再用 Route A 的参考资产和 walking cycle 强约束。

## 第一轮实验

先只做两个风格差异最大的片段：

- 月球超写实
- ASCII 数据世界

如果这两段仍能保持角色和步态一致，说明主流程可行。

## 评价指标

每次生成后按 1–5 分记录：

| 指标 | 说明 |
|---|---|
| Character | 角色外观是否稳定 |
| Gait | 步频、步幅、节奏是否稳定 |
| Position | 主体是否稳定在目标位置 |
| Background motion | 背景卷动是否自然 |
| Style | 风格是否足够明确 |
| Scene-fit | 场景与风格是否匹配 |
| Loopability | 是否容易形成或衔接 walking loop |
| Editability | 是否容易剪辑到 5 秒结构 |

## BGM 原则

暂不先锁具体音乐。优先选择：

- 节拍清晰
- BPM 稳定
- 适合 5 秒级结构变化
- 能让 walking cycle 与 beat 形成固定关系

后续确定 BPM 后，再反推单步时长和每段包含多少步。
