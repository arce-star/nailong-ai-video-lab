# 场景 × 风格映射

目标：每个 5 秒段落都使用与场景天然匹配的视觉语言，同时保持同一套横向行走逻辑。

| 段落 | 场景方向 | 风格方向 | 设计理由 |
|---|---|---|---|
| S1 | 樱花飘落的道路 / 庭院 | 板绘、纯线描、轻手绘 | 线条和飘落花瓣能形成轻盈开场 |
| S2 | 月球表面 / 月球基地外 | 超写实 | 真实光照、月尘与低重力环境强化科幻感 |
| S3 | 南极冰川 / 极地世界 | 像素风 | 冰川几何块面天然适合像素化表达 |
| S4 | 未来城市马路 | 数码风 / 赛博视觉 | 道路、LED、HUD、霓虹与高速卷动天然匹配 |
| S5 | 数据空间 / 终端世界 | ASCII 码风 | 整个世界可以由字符和终端符号构成 |
| S6 | 待定 | 待定 | 作为结尾段，需要兼顾升级感和收束感 |

## 设计原则

- 不要求 6 段统一画风；统一的是构图、动作、节奏与主体。
- 风格切换要有明显差异，最好让观众一眼看出“进入了另一个世界”。
- 场景不能只是换背景图；地面、光照、粒子、材质、空气感也要一起变化。
- 每段都必须保留清晰的地面接触与行走参照，否则 walking cycle 会显得漂浮。
- 第六段优先考虑一个具有“终点 / 汇聚 / 升级”感觉的世界，而不是再随机加一种风格。

## 第六段候选

1. 全息花园 + 半透明 holographic rendering
2. 星际高速路 + cinematic sci-fi
3. 黑白漫画宇宙 + manga ink
4. 几何低多边形世界 + low-poly 3D
5. 各前五种风格逐层叠加的混合终章
